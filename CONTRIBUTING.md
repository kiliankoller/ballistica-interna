# Contributing

**BallisticaInterna does not accept outside contributions for now.** Pull requests will not be merged and may be closed
without review. The project is a private, unpaid one: every accepted change would have to be checked against the
data sources' terms and against the safety wording, and the maintainer has no capacity for that at present.

What is welcome:

- Issues with errors, wrong or missing data records and unclear texts (please name the record and a public
  source for the correct value; do not paste load tables or other copyrighted material).
- Security problems: see [SECURITY.md](SECURITY.md) (private reporting).

**No donations and no sponsoring.** The project takes no money for now. Whether and how that could change is to
be clarified with a lawyer first.

The licences are in the README: code GPL-3.0-or-later, data ODbL 1.0.
